# l07_pebbled_leather - Pebbled / Saffiano-style leather

_Category: leather. Open the graph: `cookbook/leather/l07_pebbled_leather.ptex`._

An oxblood pebbled leather with a dense field of small rounded bumps across
the surface, closer to a Saffiano-style grain than the sharp cellular scale
edges the rest of this leather set uses.

## Recipe

Clones `crocodile_skin` but swaps its base generator: instead of `l01`,
`l02`, `l04`, `l05`, and `l06`, which all keep `voronoi_0` as a raw voronoi
(hard polygon cell edges), this material retypes it to `fbm` with `noise=2`
(Cellular 1, "worley cells, dark centers" per `docs/AUTHORING.md`'s noise
vocabulary table). `fbm`'s multi-octave sum softens and rounds the cell
interiors relative to voronoi's straight cell walls, which is what reads as
small pebble bumps instead of hard-edged scales. `scale_x`/`scale_y` are
raised to 20 (the donor's own default voronoi scale is 16) for a dense
small-pebble grain rather than a few large lumps.

Same donor-swap lever as `l03_suede`'s `voronoi_0` to `perlin` retype, just
a different target basis: `l03` trades the cell grid away entirely for a
continuous fibrous surface, this one keeps the cell structure but rounds it.

Distinguishing it from `l04_reptile_exotic`: `l04` leans INTO the raw
voronoi's hard cell edges, enlarged and elongated, for a bold sharp-scaled
exotic look. This material goes the other direction, keeping the grain
fine and dense with `fbm`'s soft rounded cell interiors, so it reads as a
manufactured pebble-grain finish (briefcase, wallet, handbag leather)
rather than a scaled hide.

Polarity note: the height ramp reuses `_dome_the_cells` unmodified. Before
assuming that was safe, the existing `fbm_2_cellular1` noise-gallery swatch
(same `noise=2`, `iterations=3`, `persistence=0.5`, a plain 0-black/1-white
ramp) was inspected directly: it shows the same dark-blob-at-cell-center
character voronoi has, so `PoreCells` port 0 is still low at the pebble
centers and high in the network between them, the polarity
`_dome_the_cells` assumes. Pebble centers dome up into small raised bumps,
the network between them recedes, matching how pebbled leather actually
looks (raised bumps, not pores/holes despite the "pores" language in the
noise vocabulary table). Oxblood palette (warmer highlight on the raised
pebble tops, darker wine in the recessed network) and matte-to-semigloss
roughness (glossier on the tops, duller in the recesses) round out the
finish, with a moderate `normal_map` `param1` of 0.5 (still `param4=0`).

## Subgraph structure

Grouped per the "Grouping into subgraphs" lever in `docs/AUTHORING.md`, via
the same shared `_group_leather_grain` helper as `l01`/`l03`/`l04` (this
donor carries no `blend` node here, so no port-source tracing applies).
Opening the graph shows 2 top-level groups (plus `Material` and the
untouched metallic `NonMetallic`) instead of the raw 7-node graph:

- **Grain Pattern** - `PoreCells` (retyped to `fbm`, `noise=2`,
  `scale_x=20`, `scale_y=20`, `folds=0`, `iterations=3`, `persistence=0.5`)
  and `LeatherColor` (the oxblood pebble albedo). Exposed: `Pebble size`
  (`PoreCells.scale_x`, explicitly tuned here unlike `l01`, which never
  touches it), `Pebble color`.
- **Surface Finish** - `GrainHeight` (height, domed via `_dome_the_cells`),
  `LeatherRoughness` (matte-to-semigloss finish), `LeatherNormal`
  (`param1=0.5`, `param4=0`, for moderate pebble relief). Exposed:
  `Finish`, `Pebble relief`.
