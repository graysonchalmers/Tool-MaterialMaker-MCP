## 🎯 The Rebuild Question

**If we started today**, knowing what got used, what the one outside builder built on, and Grayson's 2026-09-27 direction ("a smaller library, more feature-rich"), we would build:

- **The same ~1.6k-line core**, left as is: catalog, errors-as-data validator, headless Godot render with engine targets, save. It would carry two fixes:
  - A render only succeeds when Godot exits 0, every PNG decodes, and no map is flat.
  - `size` is either real or gone.
- **The cookbook shipped as package data**, so an installed wheel is not hollow.
- **One MCP `render_preview`** with the showcase's defaults and knobs. Tile and heightmap round-trip through export. Clearcoat is a judging aid only, labeled as such. The preview rig is an instrument for judging materials, not a product.
- **About 29 host materials.** Each has named, exposed feature layers: wear, wetness, growth, polish, parallax, emission. They are built from a shared layer library (`add_wear(g)`, `add_wetness(g)`, …), so a feature is written once and applied to many hosts. Node-vocabulary demos move to the Core toolbox as swatches with pixel tests.
- **A measured loop.**
  - A tiny call log.
  - A use-session count in HANDOFF.
  - Hand-edits as dated `.ptex` files in `saved_graphs/`, each with a card.
- **An intake lane for outside PRs.** CI approval for fork PRs, and a line in HANDOFF listing the open ones.
- **A thin baton.** One current-state doc, and a ledger of state plus one line per cell. Plan history lives outside the working tree.

**How far reality is from that:**
1. The core is **already there**. Its failure paths lie (the `size`, publication and download bugs); it does not need a rebuild.
2. The library is **wider, not deeper**. 74 materials reduce to about 25 topologies. 20 materials exist to prove a node, and 10 of those are the only user of their node type.
3. The loop is **unmeasured and unwalked**: 0 use-sessions, and no hand-edits since 08-28.
4. The features of the last three cycles (tile 0.45, clearcoat, heightmap) are **reachable only from `quality/` scripts**.
5. The baton and memory **cost more than they bind**. #5's verdicts evaporated.

This is subtraction plus one layer-library refactor. **Not a Rebuild.**
